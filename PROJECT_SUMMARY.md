## Project Overview

This is a **Next.js-based marketing website** for Bohm Energy, a company specializing in home battery storage solutions (thuisbatterijen) in the Netherlands. The project was originally exported from **TeleportHQ** and has undergone significant refactoring to improve code maintainability and performance.

### Key Business Domain
- **Product:** LFP battery technology (LiFeP04) for home energy storage
- **Target Market:** Dutch households looking to optimize solar panel ROI and energy costs
- **Value Proposition:** Smart home batteries that autonomously trade energy to save money

## Component Architecture

### Created Components (All with CSS Modules)

#### 1. **Header** - Main Navigation
- Top banner with email/phone
- Logo and navigation menu
- Contact CTA button
- Props: `email`, `phone`, `logoImage`, `navItems[]`, `contactButtonText`

#### 2. **Button** - Reusable CTA
- Configurable text and styling
- Background images support
- Click handlers
- Props: `text`, `backgroundImage1`, `backgroundImage2`, `onClick`, `className`

#### 3. **TrustBadge** - Social Proof Display
- Shows trust indicators (e.g., "400+ clients")
- Dual badge layout with divider
- Props: `text1Part1`, `text1Part2`, `icon1`, `dividerImage`, `text2Part1`, `text2Part2`

#### 4. **FeatureCard** - Interactive Feature Display
- Expandable card with icon
- Circular image display
- Plus button for expansion
- State management (useState)
- Props: `icon`, `title`, `description`, `image`, `iconColor`

#### 5. **FeaturesSection** - Card Grid Container
- Renders children (FeatureCards) in responsive grid
- Props: `children`

#### 6. **InfoSection** - Content Blocks
- Two-column layout (text + image)
- Reversible layout direction
- Integrates Button component
- Logo display support
- Props: `title`, `highlightedTitle`, `description`, `buttonText`, `image`, `logo`, `reverse`

#### 7. **SectionHeading** - Section Titles
- Styled headings with highlighted text
- Subtitle support
- Props: `text`, `highlightedText`, `subtitle`

#### 8. **Footer** - Site Footer
- Logo and contact info
- Multi-column link sections (About, Support, Connect)
- Copyright and designer credit
- Props: `logoImage`, `phone`, `email`, `address`, `aboutLinks[]`, `supportLinks[]`, `connectLinks[]`

#### 9. **CookieBanner** - GDPR Compliance
- Cookie consent UI
- Accept/Close handlers
- Privacy policy link
- Props: `title`, `description`, `privacyPolicyText`, `onClose`, `onAccept`

## Python Backend Integration (AI/ML)

The project now includes a Python FastAPI backend for energy prediction and simulation.

### Backend Structure ('backend/')
- **Framework:** FastAPI
- **ML Models:** XGBoost (Production Prediction)
- **Key Endpoints:**
  - 'POST /predict': Predict PV generation based on weather data.
  - 'POST /simulate': Run 24h energy simulation (PV + Battery + Consumption).
  - 'POST /maintenance': Analyze system performance and detect faults.

### Frontend Integration
- **Service:** 'lib/services/pythonApi.js' handles API communication.
- **Pages:**
  - 'pages/predictions/index.jsx': Visualizes energy forecast and AI recommendations.
  - 'pages/maintenance/index.jsx': Displays system health and performance analysis.
